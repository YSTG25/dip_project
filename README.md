# **Multimodal Perception and Reasoning System**

This project implements a comprehensive video analytics pipeline that integrates real-time object detection and tracking with a semantic Reasoning Layer powered by Vision-Language Models (VLMs). The system is designed to provide high-level situational awareness by combining discriminative perception with generative reasoning.

---

## **Project Overview**

Traditional computer vision models are limited to class-based identification. This architecture bridges the gap between perception and understanding by:

1. **Object Tracking:** Utilizing YOLOv8 and ByteTrack to maintain temporal consistency and unique object identification across video frames.  
2. **Contextual Extraction:** Isolating specific regions of interest based on detection metrics for deep analysis.  
3. **Semantic Reasoning:** Deploying VLMs (Moondream or LLaVA) via the Ollama framework to generate descriptive assessments and safety risk evaluations.  
4. **Integrated Visualization:** Rendering the AI's analytical output into a custom-engineered side-panel user interface.

---

## **System Architecture**

The pipeline is organized into two primary operational stages:

### **1\. Perception Layer**

The system utilizes YOLOv8 for high-frequency object detection. The ByteTrack algorithm is integrated to manage data association, ensuring that trackers persist through partial occlusions and varying lighting conditions.

### **2\. Reasoning Layer**

To optimize computational resources, the system triggers the VLM at a configurable interval (defaulting to every 60 frames). The primary detection is cropped and transmitted to the language model to perform zero-shot reasoning regarding the object's function and potential safety implications.

---

## **User Interface Design**

The interface is developed using the OpenCV framework and includes the following features:

* **Primary Stream:** Displays the source video with overlaid bounding boxes, tracking IDs, and confidence scores.  
* **Reasoning Panel:** An expanded 350-pixel canvas on the right dedicated to displaying real-time semantic updates.  
* **Text Wrapping Logic:** A custom rendering engine designed to handle multi-line string outputs, ensuring high-density information remains legible within the panel constraints.

## **Installation and Configuration**

### **Prerequisites**

* Python 3.10 or higher  
* NVIDIA GPU with CUDA support (Minimum 4GB VRAM recommended for local execution)  
* Ollama Service (Running as a background process)[after installing ollama do "ollama serve" in a terminal and keep it running.]

### **Local Model Deployment**

The following models must be pulled via the Ollama CLI prior to execution:

Bash  
ollama pull moondream  
\# Alternative: ollama pull llava

### **Dependency Installation**

Bash  
pip install ultralytics supervision ollama numpy opencv-python

## **Performance Optimization**

To maintain stability on mobile workstations and laptops:

* **GPU Isolation:** The perception and reasoning tasks are managed to prevent VRAM overflow.  
* **Selective Inference:** The system only processes crops that meet minimum dimension requirements (50x50 pixels) to ensure data quality for the VLM.  
* **Thread Synchronization:** Utilizes non-blocking log output to prevent console buffering from impacting the video write speed.
